# Evolution Arena v3

Prototype 3D multijoueur navigateur.

- Caméra TPS derrière l'animal.
- Orientation uniquement au ZQSD : Z avance, S recule, Q/D tournent.
- Clic gauche = une attaque manuelle, avec cooldown.
- Barre de vie au-dessus des joueurs et des mobs.
- Dégâts affichés à chaque coup.
- Mort : le joueur reste mort jusqu'à R ou au bouton de respawn, puis revient ver de terre niveau 1 au spawn avec 5 s d'invincibilité et invisibilité.
- 20 espèces et progression par zones.
- Rivière, cascade, relief, végétation, rochers et éclairage/ombres améliorés.
- Musique d'ambiance continue générée par Web Audio après l'entrée dans le jeu.
- Classement des joueurs réels uniquement.

## Lancer
npm install
npm start

Puis ouvrir http://localhost:3000

## Déploiement
Le projet peut être redéployé sur ton Web Service Render existant. Une fois les changements poussés dans le dépôt GitHub connecté à Render, le déploiement automatique met à jour le même lien public.
