# Evolution Arena v10

Version focused on a complete lobby rebuild and safe spawning.

## Lobby
- Dedicated pseudo area.
- SPAWN button and Enter key to spawn.
- JOUER / BOUTIQUE tabs rebuilt.
- Cosmetic shop with 10 visual items.
- Jungle animated background.

## Gameplay
- Player spawn is constrained to a safe central zone.
- Client places player well above the terrain to prevent underground spawning.
- Respawn uses the same safe spawn zone.
- ZQSD movement and left click attack.

## Deploy
Keep the same Render Web Service and the same GitHub repository. Replace the project files, commit the changes, and let Render redeploy.
