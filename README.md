# Evolution Arena — V14

Multiplayer browser game with 20 animal evolutions.

## V14 changes
- Right mouse button + mouse movement rotates the third-person camera.
- Q turns right, D turns left.
- Mobile touch controls: virtual joystick, attack, sprint and camera swipe.
- Player and mob walk/run animations move the legs; the worm undulates in a side-to-side zig-zag.
- Animal models rebuilt with large heads, big expressive eyes and mouths, while keeping distinct species details.
- Denser continuous terrain mesh and safer ground placement to avoid visible gaps/floating models.
- Live circular minimap with player dots, bot dots, rivers and local world view.
- Temporary pickups: speed, power and shield boosts.
- Edible plants restore HP and give a little XP to small predators (up to level 5).
- More varied environmental zones and nature, while keeping object counts controlled for performance.
- Fewer mobs and smoother interpolation to reduce freezes.
- Coins remain attached to the same server session when returning to the lobby.

## Controls
- PC: Z forward, S backward, Q turn right, D turn left, Shift sprint, left click attack, right click + mouse camera, R respawn.
- Mobile: left joystick move/turn, ⚔ attack, ⚡ sprint, swipe the right side to move the camera.
